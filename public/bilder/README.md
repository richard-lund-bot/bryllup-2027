# Bildemappe

Familiebilder levert av Richard, nedskalert til maks 1600 px (JPEG ~80 % kvalitet) for nettbruk.
Alt her er offentlig tilgjengelig via nettsiden – legg aldri private bilder her.

## Sortering (etter filnavn-prefiks)

| Prefiks | Innhold |
|---|---|
| `par-*` | Richard og Jennie sammen (flagg = 17. mai ved huset, barnevogn, sjøen, ultralyd, iskrem) |
| `familie-*` | Hele familien (sommer, jul, svarthvitt, dåp ute, kirken, ferie, restaurant) |
| `hverdag-*` | Hverdagsglimt (lesestund, sofa, snømann, skogstur, smil) |
| `nyfodt-*` | Fra sykehuset med nyfødt og storebror |

## Brukes i dag

- `par-flagg.jpg` – bakgrunn i toppen av invitasjonssiden
- `par-barnevogn.jpg` – velkomstseksjonen
- Galleriet «Litt av oss»: familie-sommer, par-sjoen, familie-jul, hverdag-snomann,
  familie-kirken, hverdag-skogstur, par-ultralyd, hverdag-lesestund, par-iskrem

Bytt bilder ved å redigere `GALLERI`-listen øverst i `src/pages/Invitasjon.tsx`.

Fire opplastede bilder ble bevisst **ikke** lagt inn her: to Snapchat-skjermbilder med
app-grensesnitt, ett privat sofabilde og fødselsbildet fra sykehuset.
